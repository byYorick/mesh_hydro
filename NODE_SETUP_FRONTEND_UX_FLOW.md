# Frontend UX Flow: Добавление узлов

## Обзор

Пошаговое описание как пользователь добавляет узлы через веб-интерфейс.

---

## 1. Главная страница - Обнаружение новых узлов

### 1.1 Навигация

В главном меню появляется уведомление:


```vue
import { ref, computed, onMounted, onUnmounted } from 'vue'
import { useNewNodesStore } from '@/stores/newNodes'
import { useWebSocket } from '@/composables/useWebSocket'

const store = useNewNodesStore()
const ws = useWebSocket()

const newNodes = computed(() => store.newNodes)
const newNodesCount = computed(() => newNodes.value.length)
const wsConnected = ref(false)
const showNewNodeToast = ref(false)
const latestNode = ref(null)

onMounted(() => {
  // Загрузить новые узлы
  store.fetchNewNodes()
  
  // Подключиться к WebSocket
  ws.connect()
  
  // Слушать события
  ws.on('connected', () => {
    wsConnected.value = true
  })
  
  ws.on('disconnected', () => {
    wsConnected.value = false
  })
  
  ws.on('new-node-discovered', (node) => {
    // Добавить в список с анимацией
    latestNode.value = node
    showNewNodeToast.value = true
    
    // Звуковое уведомление
    playNotificationSound()
  })
  
  ws.on('node-heartbeat', ({ mac_address, last_heartbeat_at }) => {
    // Обновить heartbeat
    const node = newNodes.value.find(n => n.mac_address === mac_address)
    if (node) {
      node.last_heartbeat_at = last_heartbeat_at
      node.is_online = true
    }
  })
  
  ws.on('node-configured', ({ mac_address }) => {
    // Удалить из списка новых (с анимацией)
    const index = newNodes.value.findIndex(n => n.mac_address === mac_address)
    if (index !== -1) {
      // Анимация fade-out
      const element = document.querySelector(`[data-mac="${mac_address}"]`)
      if (element) {
        element.classList.add('fade-out')
        setTimeout(() => {
          store.newNodes.splice(index, 1)
        }, 300)
      }
    }
  })
})

function getNodeIcon(nodeType: string): string {

}

  })
}
```

## Итого: Пользовательский опыт

### Для ROOT (первый раз):
**Время:** 5-7 минут
1. Подключить питание (10 сек)
2. Подключиться к WiFi AP (30 сек)
3. Ввести WiFi credentials в браузере (1 мин)
4. Заполнить параметры (2 мин)
5. Ждать перезагрузку (20 сек)
6. ✅ Готово!

### Для обычной ноды:
**Время:** 2-3 минуты
1. Подключить питание (10 сек)
2. Ждать mesh подключения (30 сек)
3. Ввести PIN + параметры (1 мин)
4. Ждать перезагрузку (20 сек)
5. ✅ Готово!

### Для опытного пользователя (batch):
**Время:** 5-7 минут на 5 узлов
1. Подключить все 5 узлов к питанию
2. Дождаться пока все появятся в списке
3. Выбрать все чекбоксами
4. Ввести общие параметры
5. Применить ко всем
6. ✅ Готово!
