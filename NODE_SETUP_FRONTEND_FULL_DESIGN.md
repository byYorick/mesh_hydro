# Полный дизайн веб-интерфейса: Система добавления узлов

## 1. Общее представление

**Цель:** Предоставить пользователю наглядный и интуитивный интерфейс для добавления ROOT и обычных узлов в сети гидропонной системы mesh_hydro.

**Ключевые возможности интерфейса:**
- Автоматическое обнаружение новых устройств (в реальном времени)
- Пошаговый мастер настройки для ROOT узлова и обычных нод
- Пакетная настройка нескольких узлов
- Встроенные подсказки, визуальные индикаторы статуса, проверка ошибок
- Адаптивный дизайн для настольных и мобильных устройств

## 11. Уведомления и анимации

- **Toast** при обнаружении узла: появляется сверху справа
- **Snackbar** при ошибках (PIN неверный, offline)
- **Анимации:**
  - Карточки новых узлов: `slideIn` + подсветка
  - Удаление после настройки: `fadeOut` + перемещение в список настроенных
  - Статус онлайн/offline: `pulse` эффект

## 12. Пользовательские сценарии

### Сценарий A: Настройка ROOT + 3 нод (всё с интерфейсом)
```
1. Пользователь заходит на /setup → видит 1 ROOT + 3 ноды
2. Открывает мастер ROOT (4 шага)
3. После завершения ROOT, интерфейс автоматически обновляет список mesh
4. Настраивает остальные 3 ноды (по одной или пакетно)
5. В разделе "История" видит записи
```

### Сценарий B: Одновременные ROOT (несколько зон)
```
1. На экране 2 ROOT узла → каждый с уникальным PIN и mesh ID
2. Пользователь видит наклейки, выбирает нужный
3. Мастер подсвечивает выбранную mesh сеть
4. После настройки одного ROOT → другой остаётся в списке
5. Обычные ноды при настройке выбирают mesh по зоне
```
