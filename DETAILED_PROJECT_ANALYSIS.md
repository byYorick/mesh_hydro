## 🎯 ОБЩАЯ ИНФОРМАЦИЯ О ПРОЕКТЕ

### Описание

**Mesh Hydro System** — это IoT система управления гидропонной установкой на базе mesh-сети ESP32 микроконтроллеров с профессиональным веб-интерфейсом для мониторинга и управления.

### Основные возможности

1. **Мониторинг в реальном времени**
   - pH (уровень кислотности)
   - EC (электропроводность)
   - Температура и влажность
   - CO₂ и освещенность
   - Обновление каждые 5-30 секунд

2. **Автоматическое управление**
   - PID контроль pH/EC с адаптивными коэффициентами
   - Управление перистальтическими насосами
   - Контроль климата (форточки, вентиляция, свет)
   - Полив по зонам

3. **Mesh-сеть ESP32**
   - Самоорганизующаяся топология
   - ROOT узел как MQTT мост
   - Автоматическая регистрация узлов
   - Отказоустойчивость

4. **Веб-интерфейс**
   - Vue 3 + Vuetify 3 (Material Design)
   - Real-time обновления через WebSocket
   - Интерактивные графики
   - Управление всеми узлами
   - Адаптивный дизайн

5. **Backend API**
   - Laravel 11 с PostgreSQL
   - REST API
   - MQTT интеграция
   - Telegram/SMS уведомления

### Целевые пользователи

- Владельцы гидропонных ферм
- Тепличные хозяйства
- Домашние энтузиасты гидропоники
- Образовательные учреждения
- Исследовательские лаборатории

### Компоненты по слоям

#### Hardware Layer (ESP32)

1. **ROOT NODE (ESP32-S3 #1)** ⭐ Критичный
   - Координатор mesh-сети
   - MQTT мост к серверу
   - Node Registry (реестр узлов)
   - Data Router (маршрутизатор данных)
   - Резервная логика климата

2. **NODE Climate (ESP32)**
   - Датчики: SHT3x, CCS811, Trema Lux
   - Только мониторинг (без исполнителей)
   - Отправка данных на ROOT

3. **NODE pH/EC (ESP32-S3 #3+)** ⚠️ Критичный
   - Датчики pH и EC (I2C)
   - 5 перистальтических насосов
   - PID контроллер
   - OLED дисплей (опционально)
   - **Автономная работа** при потере связи

4. **NODE Display (ESP32-S3 #2)**
   - TFT дисплей 240×320 (ILI9341)
   - LVGL интерфейс
   - Ротационный энкодер
   - Показ всех узлов

5. **NODE Relay (ESP32)** 🚧 Частично реализован
   - Линейные актуаторы форточек
   - Вентилятор
   - PWM диммирование света

6. **NODE Water (ESP32-C3)** 🚧 Заглушка
   - Насосы подачи/слива
   - Клапаны зон полива
   - Датчик уровня воды

#### Communication Layer

**ESP-WIFI-MESH:**
- Протокол: Собственный JSON поверх ESP-MESH
- Топология: Самоорганизующаяся древовидная
- ROOT: Единая точка выхода в WiFi/MQTT
- Типы сообщений: telemetry, command, config, event, heartbeat, request, response

**MQTT:**
- Broker: Eclipse Mosquitto 2.0
- Топики:
  - `hydro/telemetry/#` - телеметрия от узлов
  - `hydro/event/#` - события
  - `hydro/heartbeat/#` - проверка связи
  - `hydro/command/#` - команды узлам
  - `hydro/config/#` - конфигурация
  - `hydro/discovery` - регистрация новых узлов

#### Backend Layer (Laravel 11)

**Основные модули:**
1. **Models (10 моделей)**
   - Node, Telemetry, Event, Command
   - PidPreset, PumpCalibration, NodeError
   - Schedule, ConfigHistory, Setting

2. **Services**
   - MqttService - MQTT интеграция
   - TelegramService - уведомления
   - SmsService - критичные алерты
   - NodeStatusService - проверка состояния

3. **Console Commands**
   - mqtt:listen - MQTT слушатель (daemon)
   - nodes:check-status - проверка узлов
   - telemetry:cleanup - очистка старых данных
   - db:clean-test-data - очистка тестовых данных

4. **HTTP Controllers**
   - NodeController - CRUD узлов
   - TelemetryController - история данных
   - CommandController - отправка команд
   - DashboardController - агрегированные данные

#### Frontend Layer (Vue.js 3)

**Структура:**
1. **Views (9 страниц)**
   - Dashboard - главная
   - Nodes - список узлов
   - NodeDetail - детали узла
   - Analytics - аналитика
   - Events - лог событий
   - Settings - настройки
   - Documentation - справка

2. **Components (30+ компонентов)**
   - NodeCard - карточка узла
   - AdvancedChart - интерактивные графики
   - EventLog - лог событий
   - ConfigEditor - редактор конфигурации
   - CommandDialog - отправка команд
   - И многое другое...

3. **Stores (Pinia)**
   - app - общее состояние
   - nodes - узлы
   - telemetry - телеметрия
   - events - события
   - errors - ошибки

4. **Services**
   - api.ts - REST API клиент
   - echo.ts - WebSocket (Laravel Echo)
   - NodeStatusManager - управление статусами
