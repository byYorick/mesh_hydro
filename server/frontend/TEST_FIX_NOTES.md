# Исправление тестов Frontend

## Проблема
CSS файлы из Vuetify не могут быть обработаны в тестах Vitest. Ошибка:
```
TypeError: Unknown file extension ".css" for /app/node_modules/vuetify/lib/components/VCode/VCode.css
```

## Решение
Необходимо настроить обработку CSS файлов через Vite плагин или использовать другой подход.

## Варианты решения:
1. Использовать `vite-plugin-css` для обработки CSS
2. Настроить правильный порядок плагинов с `enforce: 'pre'`
3. Использовать моки для CSS импортов
4. Отключить стили Vuetify в тестах (если возможно)

## Текущий статус
Проблема не решена полностью. Требуется дополнительная настройка.
